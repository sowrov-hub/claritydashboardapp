Tips to keep your data safe 1. Always open this file in the same browser on the same device (e.g. Chrome).
2. Export a backup at end of each month before resetting for a new month.
3. Never clear your browser cache/history — it will delete saved data.
4. To use on another device: Export → copy the file → Import on the new device.
